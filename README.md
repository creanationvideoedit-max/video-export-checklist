# Video Export Checklist

A reusable manual review checklist for editors delivering short-form and social video. This is a new, AI-assisted documentation project; no adoption or usage metrics are claimed.

## How to use

Copy this checklist into delivery notes. Review the actual exported file, then the uploaded copy. Mark items only after checking them. Follow the client brief and destination requirements for export settings.

## Before export

- [ ] Confirm the correct sequence, version, aspect ratio, and duration.
- [ ] Check that source media, fonts, graphics, and audio are online.
- [ ] Save the editable project and confirm the output filename and folder.
- [ ] Confirm permission to use included footage, music, and graphics.

## Playback review

- [ ] Play the exported file from beginning to end.
- [ ] Check the first and last frames for unintended blank frames or cutoffs.
- [ ] Listen for clipped words, clicks, sudden volume changes, and unintended silence.
- [ ] Check dialogue clarity against music on headphones and speakers.
- [ ] Confirm sentence joins and pacing sound natural.
- [ ] Check captions for spelling, timing, contrast, and readable line breaks.
- [ ] Check text and important visuals against the destination interface overlays.
- [ ] Check crops, logos, transitions, and graphics at normal playback speed.
- [ ] Verify every requested revision at its timestamp in the final export.

## Delivery review

- [ ] Confirm exported dimensions, frame rate, duration, and audio match the brief.
- [ ] Upload only the approved version to the intended destination.
- [ ] Wait for processing and play the uploaded copy.
- [ ] Confirm recipient access without exposing unrelated files.
- [ ] Record the exact filename, version, review date, and remaining issues.
- [ ] Update the delivery tracker only after verifying its saved state.
